# Selected work folder

Mode: Persuade; project reading is Read. A local extension of the approved homepage.

## Direction contract

THESIS: One shared open folder holds two readable project documents. User confirmed
the shared-folder overlay interaction. Project titles remain discoverable before interaction.

OWN-WORLD: Existing neutral light/dark palette and Source Sans 3. Physical folder
tab, overlapping document edges and a shallow pocket, with restrained offset shadows.

STORY: Read project name and deliverable, select a document, read existing verified
details, then return to the same document. No additional claims or invented imagery.

FIRST VIEWPORT: Selected work heading above one broad folder; two sheets sit beside
each other on desktop, vertically stepped on mobile. The pocket overlaps only their
lower edges. Each whole sheet is a button with an explicit localized opening action.

FORM: User-pinned shared folder; no concept roll. A selected sheet travels from its
folder position into a focused reading overlay, and returns on close. Native dialog,
Escape, returned focus, visible close, bounded internal scroll and reduced motion.
No dependencies or shipping raster assets. Existing article content is the no-JS fallback.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
