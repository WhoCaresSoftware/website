# Founder portraits

Final AI-restyled Mike and XRS portraits were supplied by the user via clipboard
for this website, imported 2026-10-24. The exact external generator and prompt
are unknown; no generator or prompt attribution is inferred.

Sources: `../../brand/brand_main/assets/source/portraits/mike-studio.png` and
`xrs-studio.png` (paths relative to website root), both 1122 × 1402 pixels.
`mike.webp` and `xrs.webp` are derivatives encoded with `cwebp -q 90`.
The earlier 400 × 400 originals remain preserved as `mike.png` and `xrs.png`
in the same source directory. Preserve both sets of PNG source files.
Public display order is XRS, then Mike; XRS sits higher in the staggered pair.
This internal provenance file is excluded from the staged site.

Light-mode variants supplied by the user on 2026-10-24:
`../../brand/brand_main/assets/source/portraits/xrs-studio-light.png` and
`mike-studio-light.png`, both 1122 × 1402. These external AI-restyled images have
an unknown exact generator and prompt. The website only encodes them via
`cwebp -q 90` as `xrs-light.webp` and `mike-light.webp`; no facial edits or new
image generation were performed. All supplied PNGs and existing dark WebPs remain.
Each founder uses one lazy-loaded img inside a picture; the source chooses the
dark portrait and the fallback chooses light. Native media handles no-JS system
appearance; preferences.js updates the source condition for the effective theme.
