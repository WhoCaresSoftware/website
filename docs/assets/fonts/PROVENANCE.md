# Current website font: Source Sans 3

Source Sans 3 by Adobe, SIL Open Font License; local license `SOURCE-SANS-OFL.txt`.
Downloaded 2026-10-24 from Google Fonts v20 and converted losslessly from TTF
to WOFF2 using fontTools. Only regular (400) and semibold (600) are shipped.

- Regular: https://fonts.gstatic.com/s/sourcesans3/v20/nwpBtKy2OAdR1K-IwhWudF-R9QMylBJAV3Bo8Ky461EN.ttf
- Semibold: https://fonts.gstatic.com/s/sourcesans3/v20/nwpBtKy2OAdR1K-IwhWudF-R9QMylBJAV3Bo8Kxm7FEN.ttf
- License: https://github.com/adobe-fonts/source-sans/blob/release/LICENSE.md

The earlier Manrope source remains for historical comparison, excluded from staging.

Greek coverage verified 2026-10-24: both existing Source Sans 3 WOFF2 files contain
Greek, including accented characters used by the complete Greek translation.
These are not Latin-only subsets. Browser platform-font inspection confirms
self-hosted Source Sans 3 for Greek regular and semibold text; no new font needed.
